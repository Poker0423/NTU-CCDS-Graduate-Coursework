# Raw data

Seven tables from *Formula 1 World Championship (1950–2026)*, maintained by A. Ranjan
(https://github.com/Arths17/f1-dataset), licensed **CC0: Public Domain**. Files are unmodified;
`\N` marks missing values. See `SCHEMA.md` for field definitions.

Used tables: results, races, drivers, constructors, status, circuits, lap_times.
The analysis filters to 1950–2024; rows for 2025–2026 are ignored.
