Grid is the recorded starting position. P1 is first; a podium is P1–P3. Some positive values encode pit-lane starts. Grid 0 is excluded here.

Win and podium rates use numeric final classification and all positive-grid entries, including withdrawals. NC means no numeric final classification. The modern sample contains 305 races and 6,436 result entries, of which 6,351 have positive grid values.

Recorded gain = grid − numeric final classification. Finish-cohort gain re-ranks only positive-grid drivers with a numeric classification and Finished / Lapped / +n Laps status. It compares the same cohort; it does not remove every DNF effect, estimate overtakes or establish causality.

Reviewed grid corrects only Nasr at Italy 2015 (17→11), Ericsson at Russia 2015 (17→16), and Hülkenberg at São Paulo 2024 (17→18), with official F1 sources recorded in the accompanying correction table. Other historical issues remain.

Replay shows recorded positions at completed driver laps; it does not fill missing laps or carry a retired driver's last rank forward. Final classification is displayed separately. Rain, flags and tyre explanations require separate verified sources.

Modern scope is the recording default. Historical quick cases explicitly switch the era to all history. Replay and the fixed circuit exploration are labelled with their own populations.
